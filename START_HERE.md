# Morph Modeling — complete source project

Prototype 0.1. This archive contains the source used for the published editor,
including all application code, assets, components, configuration, the dependency
lockfile, tests, roadmap, and validation notes.

## Start locally

1. Extract the ZIP and open a terminal in the `Morph-Modeling` folder.
2. Install Node.js 22.13 or newer and pnpm 11.25.0 (the versions declared in package.json).
3. Install the dependencies and start the development server:

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Open http://localhost:5173 (or the address printed by the server).
The first dependency installation requires internet access. The editor does not
require an API key. A browser with WebGL support provides the full material preview;
otherwise the compatibility viewport uses simplified lighting.

## Check and build

```sh
pnpm exec tsc --noEmit
node --import tsx --test tests/model.test.ts tests/files.test.ts
pnpm build
```

`pnpm start` serves the built Cloudflare-compatible output locally. The original
Sites hosting configuration and build adapter are included. Deployment to a different
provider will need that provider's configuration; a Sites project ID is not a credential.

## Project map

- `app/`: application entry point and global styles.
- `components/morph/`: editor interface, UV workspace, help, and roadmap.
- `lib/morph/model.ts`: editable mesh model and geometry operations.
- `lib/morph/viewport.ts`: Three.js viewport, picking, cameras, and transforms.
- `lib/morph/files.ts`: import/export, texture handling, and local recovery.
- `tests/`: 16 tests covering geometry, serialization, and asset round-trips.
- `public/ROADMAP.md`: implemented scope, known limitations, and future milestones.
- `VALIDATION.md`: completed checks and remaining verification gaps.
- `SOURCE_MANIFEST.json`: published source commit and per-file SHA-256 hashes.

Save an editable `.morph` file from the editor to keep your scenes. User-created
browser projects live in that browser's local storage and are separate from this
source package. The starter scene is generated by the included source.

Installed dependencies (`node_modules`), generated build output, caches, and the
Git database are excluded; everything needed to install and rebuild is included.
The published source is unchanged. This quick-start guide and the source manifest
were added only to the export package.
